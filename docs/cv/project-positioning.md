# CV and Application Positioning

## What This Project Should Do For The CV

This project should not try to compete with the two NeurIPS manuscripts as a method contribution. Its job is to strengthen the background layer underneath them:

- implementation
- evaluation
- data workflow
- debugging
- ROS-compatible system integration

In other words, it should make the CV read less like "two isolated research ideas plus one robotics project" and more like "someone who can make embodied learning research actually run."

## Recommended CV Entry

**Embodied Data & Evaluation Stack for VLA Policies (VLA-ROS)**  
Multimodal data, execution, and evaluation pipeline for vision-language-action policy development

## One-Line Summary

Built a software-only multimodal data and evaluation stack for VLA policy development, connecting ROS-compatible logs, benchmark rollouts, replay, and reproducible failure analysis.

## CV Bullet Options

- Built a software-only multimodal pipeline for collecting, synchronizing, and organizing observation, action, and execution traces for VLA policy evaluation.
- Designed a reproducible evaluation workflow that connected policy rollouts with structured logging, replay, and failure inspection.
- Developed adapters that linked ROS-compatible logs and benchmark trajectories to a shared episode schema and reporting path.
- Built tooling for dataset curation, run comparison, and experiment support across embodied learning setups, with emphasis on debugging efficiency and implementation reliability.
- Used the stack to support prototype-oriented embodied AI research where data quality, evaluation consistency, and system integration were the main bottlenecks.
