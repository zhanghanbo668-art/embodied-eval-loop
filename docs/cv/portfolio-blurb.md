# CV / Portfolio Blurb

## Primary Blurb

Built a software-only embodied AI evaluation stack that converts benchmark trajectories and ROS-compatible logs into reproducible episode artifacts, replayable failure cases, and comparison-ready reports. Designed the workflow around shared schemas, config-driven runs, and analysis outputs that make policy behavior easier to test, diagnose, and communicate.

## Short CV Version

## Portfolio Version

This project focuses on research infrastructure rather than model novelty. The core contribution is a reusable workflow that ingests heterogeneous embodied AI traces, normalizes them into a shared artifact format, and produces evaluation outputs that are inspectable, reproducible, and useful for debugging. It is meant to show software judgment around artifacts, adapters, workflow design, and failure analysis in embodied learning settings.
